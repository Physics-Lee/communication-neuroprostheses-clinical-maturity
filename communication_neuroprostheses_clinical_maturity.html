Column definitions (full Table 3 caption)

Cross-subject generalization across human communication interfaces: pool, new-user adaptation, headline outcome, and data release. Groups run from the peripheral engineering reference to intracortical communication BCIs in paralyzed participants (whose IDs refer to Table 1). N = users or animals in the training pool (n/r = not reported); Population = who they are; Pool = training corpus; New-user data = what a held-out user must supply; Zero-shot = usable decoding for a new user with none of their own data (yes/no; emg2qwerty's zero-shot CER of 55.4% exists but is not usable, hence no); Few-shot = the new user contributes some of their own labeled data — more than none, at most one recording hour (0 < data ≤ 1 h) — converted at each task's own pace (yes = a ≤1 h adaptation of a held-out individual is demonstrated; unreported amounts count as no); Headline outcome = one metric per study — WER for large-vocabulary speech, CER for typing/handwriting, PER for phonemes, accuracy for closed sets — modality-specific and not comparable across rows, offline unless noted; Data = release status of the neural data itself (open / partial: some data or code public / closed).
